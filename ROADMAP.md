# Roadmap

## A — Logo Asset Generator
1. Bootstrap Go API, tests, CI, Docker and documentation.
2. Safe upload validation for SVG, PNG and WebP.
3. Favicon, Apple Touch Icon and PWA icon generation, including maskable variants.
4. Preview and user-controlled padding/background.
5. ZIP download with HTML snippets and site.webmanifest.
6. Accessible English-language UI without mandatory accounts.

## B — Brand Toolkit
Color palettes, social assets, brand guidelines, framework exports, CLI/API, saved brands, optional AI features.

MVP excludes accounts, billing, persistent uploads and AI.
